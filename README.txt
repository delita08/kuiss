WEBSITE QUIZ: HOW WELL DO YOU KNOW ATA? 🎀

ISI ZIP
- index.html : halaman website utama.

CARA PUBLIKASI GRATIS (contoh Netlify Drop)
1. Ekstrak ZIP ini.
2. Buka https://app.netlify.com/drop lewat browser.
3. Login/daftar jika diminta.
4. Unggah folder yang berisi index.html (atau ZIP/folder sesuai instruksi halaman).
5. Tunggu deploy selesai; salin URL publik yang diberikan, lalu kirim ke pacar/teman.

PENTING TENTANG PAPAN SKOR
Versi ini menyimpan papan skor di browser/perangkat yang digunakan (localStorage).
Skor dari HP berbeda TIDAK otomatis tergabung ke satu papan skor online.
Untuk leaderboard lintas perangkat, website perlu dihubungkan ke database online (misalnya Supabase/Firebase) dan konfigurasi project database tersebut.
